## DS-11 accessibility
| Check | Result |
|---|---|
| Text contrast ≥4.5:1 (light tokens) | Pass for every text/background pairing that is used. The only token pairs under 4.5 are `macroCarbs`/`macroFat` (3.56–4.36), which are used only as `ProgressTrack` fills (`MacroStrip.tsx`), where the rule is ≥3:1; plus tint/text combinations that are never rendered together (e.g. `warning` on `dangerTint`). |
| Essential boundaries ≥3:1 | `borderStrong` 3.35 surface · 3.00 surfaceSubtle · 3.14 canvas. `divider` (1.28) is decorative. White on `primary` 5.42, on `danger` 5.87. |
| Text scaling | `AppText` always allows font scaling. The only cap is the tab-bar label (`maxFontSizeMultiplier`, DS rule). Single-line rows truncate with an ellipsis, never clip. The large-text matrix is POST-13. |
| Screen readers | Every custom pressable has a role and a label. The two without are the scrims in `BottomSheet` / `ConfirmationDialog`, which are deliberately `accessible={false}`; the modal has `accessibilityViewIsModal` + `onAccessibilityEscape`. |
| Gesture alternatives | Date: prev/next buttons + calendar + increment/decrement on the strip (UX-02). Ruler: adjustable actions + direct entry (M4). Meals and Search results reorder: Move up/Move down actions. Custom-food swipe delete: `Delete food` action. |

No code changes needed.
